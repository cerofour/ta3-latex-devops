  \section{Implementación del Nodo IoT}
  
  Para la implementación del nodo IoT se utilizó un microcontrolador
  ESP32 que se utilizará para recibir mediciones desde
    la nube y un sensor ultrasónico para medir la próximidad
    de objetos. A continuación se detalla la lista de materiales
    utilizadas para la elaboración.

    \begin{itemize}
      \item \textbf{ESP32 WROOM-32}: es un microcontrolador
      con Wifi y Bluetooth incluído, ideal para recibir lecturas
      de sensores y enviarlas a través de internet.
      \item \textbf{HC-SR04}: sensor ultrasónico utilizable para
      medir la distancia en centímetros utilizando la velocidad del
      sonido con la siguiente fórmula.
      \begin{equation}
        D = \frac{T * 0.034}{2}
      \end{equation}
      \item \textbf{Protoboard}: utilazada para conectar los
      sensores al controlador.
      \item 4 jumpers macho-macho.
      \item Un cable Micro USB a USB.
    \end{itemize}
